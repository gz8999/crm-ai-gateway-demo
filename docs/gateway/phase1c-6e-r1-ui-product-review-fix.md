## Risk Detail Loading

- Read-only endpoint: `GET /api/decision-opportunities/:token`.
- Cache key: `mode|scenarioId|token`.
- Maximum concurrency: 3.
- Duplicate in-flight requests share one Promise.
- Cached rows are not requested again after scroll or render.
- `AbortController` cancels stale active requests when scope changes.
- A generation gate rejects stale queued responses.
- A failed row exposes a local retry and does not fail the page.
- `IntersectionObserver` starts loading only for visible queue rows.

Automated tests execute concurrency, deduplication, cache reuse, stale cancellation, and key construction.

## Action Integrity

Action Board only reorganizes actions already present in the Decision Pack. It does not call a model or write to CRM. Owner, due date, and status are displayed only when the Provider supplied them. Missing or tokenized ownership is rendered as `待人工指定`; missing due date or status is rendered as `待人工确定`. No uniform 2/7/30-day value is generated by the product layer.

## Audit Safety

The formal Audit page receives only the current safe view, provider status, safe transformation counts, and an allowlisted projection of audit metadata. It does not render a Safe Context payload, raw CRM data, prompts, responses, identity, or exact amount data.

Safe Context fingerprinting recursively sorts object keys while preserving array order, then computes SHA-256 through Web Crypto. The UI label is exactly `客户端上下文指纹（非服务端审计凭证）`. This value stays in browser memory and never substitutes for a missing historical server hash; missing hashes display `当前审计源未提供`. Unproven transformation counts display `未记录`.

The comparison placeholder is: `外部模型对比尚未启用，完成安全授权和 Provider 配置后开放。`

## Legacy Isolation

- The formal `App` has zero static import of the AI Lab, raw CRM operations, Transform, Import, or Reset dependencies.
- In development, the exact `/internal/ai-lab` path loads `InternalAiLab` through `import()` only.
- In production, any `/internal/*` route displays `内部工具不可用` without loading the Lab module.
- The production build emitted only the formal `index` JavaScript and CSS assets; it emitted no AI Lab chunk.
- A cross-platform Node verifier scans production assets for the internal module/path, Raw CRM title, Transform button, and sensitive legacy field markers.
- Browser verification of the production preview confirmed the unavailable page and zero console warnings/errors.

At 760px, filters stack vertically, navigation remains inside its own row, the safety status wraps, queue rows collapse behind the mobile control, the safety rail enters document flow, and Audit rows stack into labeled records.
