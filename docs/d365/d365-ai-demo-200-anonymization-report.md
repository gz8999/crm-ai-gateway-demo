# 200条 Demo 数据脱敏说明

## 原则

1. 实际CRM文件只用于聚合统计和字段结构参考。
2. 所有客户名称均重新组合并带“（演示）”标识。
3. 联系人不使用姓名，只使用业务联系人/决策联系人Token和角色。
4. 营业负责人使用合成角色名称，不使用源文件人员。
5. 案件名称、客户需求、提案内容和说明全部重新生成。
6. 金额按部门区间重新采样，并主动避开源表精确金额。
7. Timeline不复述源文件说明，会议内容全部重新撰写。
8. Signal只保存脱敏摘要，不含客户身份、精确金额或Timeline原文。
9. 不生成GUID、邮箱、电话、生产环境地址或真实Record ID。

## 验证结果

- 客户名称精确重合：0
- 案件名称精确重合：0
- 案件说明精确重合：0
- 预算金额精确重合：0
- GUID：0
- Email：0
- 电话号码：0
- 生产环境Hostname：0
